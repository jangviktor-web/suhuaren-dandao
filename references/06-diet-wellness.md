# 苏华仁 · 饮食调理与日常养生

> 来源：吴云青口传 + 苏华仁著作中反复出现的饮食观

## 一、全素食铁律

### 吴云青的素食观
> "鸡鸭鱼肉蛋，都是大坏蛋；吃啥像啥。"

苏华仁传：吴云青把全素食作为收徒第一条件。原因有三：

1. **清净身心**：荤腥产生浊气，阻碍气机运行。内丹修炼需要身体干净、经络通畅
2. **杀生业力**：食肉与道家"慈心于物"的宗旨相悖
3. **酸性体质**：肉类使体质偏酸，酸性体质是慢性病的温床

### 素食范围
```
✅ 可食：五谷杂粮、蔬菜、水果、豆制品、坚果、菌菇
❌ 不可：鸡肉、鸭肉、鱼肉、猪肉、牛肉、羊肉、蛋类、奶制品
⚠️ 争议：苏华仁著作中未见对葱蒜等五荤的明确态度
```

## 二、饮食调理公式

### 公式1：胃气判断法
```
病中/病后饮食判断：
├── 能食（有饥饿感、饮食知味）→ 胃气恢复，预后良好
│   └── 宜：清淡素食、粥汤、易消化
├── 不能食（无食欲、食不知味）→ 胃气未复，先健脾开胃
│   └── 宜：山药粥、小米粥、少量多餐
└── 损谷则愈（大病初愈）→ 减食优于多食
    └── 原理：大病后脾胃虚弱，消化能力有限，多吃反伤胃
```

### 公式2：疾病饮食禁忌
```
不同症状的饮食调整：
├── 上火（口干舌燥、便秘）→ 忌辛辣、煎炸
├── 寒湿（怕冷、腹泻）→ 忌生冷、瓜果过量
├── 肾虚（腰膝酸软）→ 宜黑豆、黑芝麻、核桃、山药
├── 失眠 → 晚餐宜少，睡前不食
└── 三高 → 低盐、低油、低糖
```

### 公式3：练功前后饮食
```
练功前：
├── 饭前1小时 → 可练功（空腹最佳）
├── 饭后 → 至少间隔1小时（饱腹练功伤胃）
└── 练功前 → 不宜大量饮水

练功后：
├── 收功后 → 静坐片刻再进食
├── 宜温食 → 练功后身体温热，避免冷饮冷食
└── 忌暴食 → 练功后脾胃运化加快，但仍需节制
```

## 六、房室养生

苏华仁著作中涉及但未详述。基本态度：
- 精为生命根本，"勿摇汝精"（广成子）
- 修炼筑基阶段须节制房事（"闭地户"即含此意）
- 筑基成功标志之一："男子无梦遗精漏，女子无经水月行"
- 道家有专门的房中养生术（七损八益等），但苏华仁未在公开著作中详述
