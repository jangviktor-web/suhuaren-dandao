# 苏华仁 · 养生决策启发式

## 一、辨体质与病机捷径

### 规则1：精气神三层辨证
```
问题定位：
├── 精力不足/腰膝酸软/慢性病 → 精亏（炼动功）
├── 气短乏力/消化不良/免疫低 → 气虚（调呼吸+动功）
└── 失眠焦虑/心神不宁/思虑过 → 神耗（凝神静功）
```
**原文**："精少则病，精尽则死"（孙思邈）

### 规则2：慢性病=肾虚公式
```
任何慢性病 → 先查肾
├── 肾虚 → 动功八式（肾的健美操）
└── 非肾虚 → 再看其他脏腑
```
**原文**："慢性病的根源就是肾虚和酸性体质"

### 规则3：酸性体质判断
```
体质偏酸 → 全素食 + 动功排浊（天地人回春功164次自然抖动）
```

## 二、功法选择决策

### 规则4：动功静功匹配公式
```
养生需求：
├── 身体层面（精力/腰肾/免疫） → 动功为主（站功八式）
├── 心神层面（失眠/焦虑/思虑） → 静功为主（七法次第）
└── 全面调理                    → 动功+静功，性命双修
```

### 规则5：功法递进顺序
```
入门→精通：
1. 先动功（站功八式，每日早晚15-30分钟）
2. 动功纯熟后 → 加静功一至三法
3. 通关后 → 静功四至七法
4. 最终 → 九节玄功或皇极阖辟功
```
**原文**："关未开，休打坐，如无麦子空挨磨"（许真人）

### 规则6：功法鉴别矩阵

| 功法 | 适用人群 | 核心作用 | 入门难度 | 禁忌 |
|------|---------|---------|:---:|------|
| 站功八式 | 所有人 | 添油接命、炼肾生精 | ★ | 无 |
| 静功七法 | 有一定基础者 | 炼精化气、通周天 | ★★ | 开关未开不可打坐 |
| 边治中养生长寿术 | 所有人 | 做功于下丹、细胞长寿 | ★ | 无 |
| 九节玄功（吕祖） | 进阶修行者 | 九转还丹全诀 | ★★★ | 需明师指导 |
| 皇极阖辟功（尹真人） | 进阶修行者 | 十步提金丹 | ★★★ | 需明师指导 |
| 陈抟二十四式坐功 | 有一定基础者 | 节气导引、经络调理 | ★★ | 按时令 |

## 四、修炼火候决策

### 规则9：四时功匹配
```
最佳练功时段：
├── 卯时（5-7点）→ 动功，顺应阳气升发
├── 午时（11-13点）→ 静功，养心守神
├── 酉时（17-19点）→ 动功，顺应阴气收敛
└── 子时（23-1点）→ 静功或休息
```
**原文**：吴云青百年如一日的子午卯酉四时功

### 规则10：练功频率与时长
```
站功八式：每日早晚各1次，每次15-30分钟
静功七法：
├── 初阶（一至三法）：每日早晚30-45分钟
├── 中阶（四至六法）：每次45分钟-1小时
└── 高阶（第七法）：24小时气运全身（侧卧功）
```

## 五、预后判断

### 规则11：修炼效验标志
```
正效验：
├── 口中津液增多（金津玉液）→ 肾气恢复
├── 身体变轻（身轻如燕）→ 浊气排出
├── 皮肤改善（橘子色/红润）→ 气血充盈
└── 精力充沛、睡眠改善 → 整体提升
```
**原文**：苏华仁自述修炼效验

### 规则12：筑基成功标志
```
筑基成功：
├── 男子 → 无梦遗精漏
├── 女子 → 无经水月行
└── 全身如火炉汗流（九节玄功筑基验相）
```
**原文**："坐断血河，筑基功成，男子无梦遗漏精，女子无经水月行"

### 规则13：警示信号
```
需停止或调整：
├── 练功后持续疲劳→ 过度，减量
├── 头晕心慌 → 呼吸方法不对，调整
├── 关节疼痛 → 姿势不对，纠正
└── 上火燥热 → 火候过猛，降为文火
```

## 六、饮食禁忌决策

### 规则14：全素食铁律
```
苏华仁养生 → 必须全素食
├── 不可：鸡鸭鱼肉蛋奶
├── 可：五谷杂粮、蔬菜水果、豆制品
└── 吴云青说："鸡鸭鱼肉蛋，都是大坏蛋；吃啥像啥"
```

### 规则15：饮食调理公式
```
病后调养 →
├── 能食 → 胃气恢复，预后良好，清淡饮食
├── 不能食 → 胃气未复，先健脾开胃
└── 损谷则愈 → 大病后减食比多吃好
```
