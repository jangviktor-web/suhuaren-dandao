# 苏华仁 · 修炼度量与养生条辨框架

> 将苏华仁体系中的"剂量"概念适配为修炼的时间/次数/火候度量，并总结养生调理七步框架。

---

## 一、修炼度量体系

### 1.1 动功度量

| 功法 | 单次时长 | 频率 | 强度 |
|------|:---:|:---:|------|
| 站功八式 | 15-30分钟 | 每日早晚各1次 | 意念青春、面含微笑、自然放松 |
| 边治中养生长寿术 | 15-30分钟 | 每日1-2次 | 做功于下丹（肾/会阴） |
| 钟离权八段锦 | 10-15分钟 | 每日1次 | 配合呼吸、自然舒展 |
| 太极尺 | 5分钟起 | 卯酉时各1次 | 柔、和、静、运、动五诀 |

### 1.2 静功度量

| 功法 | 单次时长 | 进阶周期 | 火候 |
|------|:---:|:---:|------|
| 静功七法·第1法 | 30分钟 | 早晚各1次 | 武火（深长有力呼吸） |
| 静功七法·第3法 | 45分钟 | 每日1次 | 文火（柔和绵长呼吸） |
| 静功七法·第5法 | 1-2小时 | 每日1次 | 温养（勿忘勿助） |
| 九节玄功·筑基 | 每次一点钟 | 日2-3次 | 先武后文 |
| 九节玄功·全节 | 每次一点钟 | 日2-3次 | 按节次调整 |
| 陈抟二十四式 | 按节气定时 | 每日子丑时 | 配合经络 |

### 1.3 火候三态

| 火候 | 呼吸特征 | 适用阶段 | 目的 |
|------|---------|---------|------|
| **武火** | 深长有力，快速鼓荡 | 开关、采药、烹炼 | 聚气通关 |
| **文火** | 柔和绵长，不徐不急 | 凝神、温养、守中 | 温养蓄气 |
| **沐浴** | 息微若无，恍恍惚惚 | 各阶段间隔 | 休整消化 |

**口诀**："武火采药，文火温养；朝屯暮蒙，沐浴卯酉"（《周易参同契》火候学说）

### 1.4 修炼进阶时间线

| 阶段 | 时长 | 核心功法 | 目标 |
|------|:---:|---------|------|
| 入门 | 100天 | 动功八式 + 背经 | 食素适应、经典烂熟 |
| 筑基 | 100天 | 动功 + 静功1-3法 | 关通、精固 |
| 小成 | 1-3年 | 动功 + 静功4-7法 | 小周天通 |
| 中成 | 3-10年 | 九节玄功/皇极阖辟 | 五气朝元 |
| 大成 | 10年+ | 九转还丹全诀 | 天人合一 |

## 二、养生调理七步条辨框架

> 对标中医"条辨分析七步法"，适配为苏华仁养生调理框架。

### 步骤1：问症状
```
收集信息：
├── 主诉症状
├── 持续时间
├── 加重/缓解因素
└── 伴随症状
```

### 步骤2：辨精气神
```
定位问题在哪个层面：
├── 精亏 → 腰膝酸软、精力不足、慢性病、耳鸣
├── 气虚 → 气短乏力、消化不良、易感冒、自汗
└── 神耗 → 失眠、焦虑、心神不宁、记忆力下降
```

### 步骤3：查肾本
```
肾虚判断：
├── 腰酸膝软 → 肾虚
├── 小便频数/夜尿多 → 肾阳不足
├── 头晕耳鸣 → 肾精亏损
├── 怕冷/怕热 → 肾阴/阳偏虚
└── 性功能减退 → 肾精不足
```

### 步骤4：定功法
```
根据辨证结果选择：
├── 精亏 → 动功为主（站功八式·太极回春功）
├── 气虚 → 动功 + 呼吸吐纳
├── 神耗 → 静功为主（凝神膻中 → 神息相依）
└── 综合 → 动功+静功，性命双修
```

### 步骤5：定火候
```
根据体质定强度：
├── 体质强壮 → 武火为主，较长练功时间
├── 体质一般 → 文武交替，标准时长
├── 体质虚弱 → 文火为主，从短时间开始慢慢增加
└── 老年人/重病后 → 动功从5分钟起渐进，静功先不做
```

### 步骤6：调饮食
```
配合功法调整饮食：
├── 全素食（基本原则）
├── 精亏 → 多食黑色食物（黑豆、黑芝麻）
├── 气虚 → 易消化素食，不食生冷
├── 神耗 → 晚餐宜少，睡前不食
└── 所有情况 → 大病后损谷则愈
```

### 步骤7：观效验
```
观察调理效果：
├── 正效验（继续）：
│   ├── 口中津液增多
│   ├── 身体变轻
│   ├── 皮肤红润
│   └── 精力恢复
├── 偏效验（调整）：
│   ├── 持续疲劳 → 减量
│   ├── 头晕心慌 → 调呼吸
│   ├── 关节疼痛 → 纠姿势
│   └── 上火燥热 → 降火候
└── 无效（重新辨证）：回到步骤1
```

## 三、常见症状调理速查

| 症状 | 辨证定位 | 推荐功法 | 注意事项 |
|------|---------|---------|---------|
| 失眠 | 神耗（心神不宁） | 静功第1-2法（凝神膻中）+ 侧卧功 | 晚餐少食，睡前2小时不练动功 |
| 腰膝酸软 | 精亏（肾虚） | 太极回春功 + 两仪回春功 | 重点转肩带动腰部 |
| 消化不良 | 气虚（脾虚） | 天地人回春功（排浊） + 龙游功 | 配合清淡素食 |
| 焦虑烦躁 | 神耗（心火旺） | 静功凝神法 + 上元功 | 意念不要太重 |
| 免疫力低 | 精亏+气虚 | 站功八式全套 | 坚持每日2次 |
| 高血压 | 综合 | 动功轻柔为主 + 育天池按摩 | 避免武火和剧烈动作 |
| 糖尿病 | 精亏（肾阴虚） | 回春功系列 + 全素食 | 注意饮食配合 |
| 关节痛 | 气虚（经络不通） | 龙游功 + 龟缩功 | 循序渐进不蛮练 |

## 四、修炼禁忌速查

| 禁忌 | 原因 | 替代做法 |
|------|------|---------|
| 饱腹练功 | 伤脾胃 | 饭后间隔1小时 |
| 大怒后练功 | 气机逆乱 | 先平复情绪 |
| 房事后立即练功 | 精气已泄 | 休息恢复后再练 |
| 雷电天气户外练功 | 天地气场紊乱 | 室内练或暂停 |
| 女性经期剧烈动功 | 气血下行 | 改为轻柔或暂停 |
| 酒后练功 | 神志不清 | 绝对禁止 |
| 熬夜后强练 | 气血已亏 | 先休息恢复 |
| 盲修不用师 | 易出偏差 | 定期请明师指导 |
