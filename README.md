## 使用示例

**养生辨证**
> **Q**：我经常腰膝酸软、精力不足，怎么调理？
> **A**：这是典型的**精亏**——肾虚的表现。先用精气神三层辨证定位：腰膝酸软+精力不足→精亏层面。按慢性病=肾虚公式，核心在炼肾生精。推荐：**站功八式**，每天早晚各15-30分钟，重点练太极回春功（活肾生津，8次）+ 天地人回春功（抖动164次排浊气）。配合全素食，三个月可见效。

**功法选择**
> **Q**：我失眠严重，选动功还是静功？
> **A**：失眠属于**神耗**层面——心神不宁。按功法选择公式：心神问题→静功为主。优先练**静功七法第一法"凝神回视膻中处"**——武火呼吸，凝神膻中聚阳气，每天早晚各30分钟。晚餐少食，睡前不练动功。等睡眠改善后，再加动功炼肾，达到性命双修。

**经典解读**
> **Q**：老子说"深根固蒂，长生久视"，是什么意思？
> **A**：这句话出自《道德经》第59章。"根"就是肾，"蒂"就是命门。什么叫深根固蒂？就像一棵大树，根扎得深深的根本不动摇，枝叶自然繁茂。吴云青老人为什么能活160岁？因为他把肾这个"根"练深了、把命门这个"蒂"固牢了。怎么做到？就是**添油接命**——站功八式炼肾生精，给生命这盏灯不断添油。

**吴云青实证**
> **Q**：吴云青老人坐化后真的肉身不腐吗？
> **A**：吴云青老人1998年9月20日酉时坐化。当日子时停止呼吸后，我亲手把脉——**心脏又规律跳动了1小时30分钟**。三天后周身肌肤仍栩栩如生。2000年12月24日（839天后）开缸，全身皮肤完整无缺、色泽红润、触感柔软富有弹性，常年赤脚磨出的老茧清晰可见。九华山专家评价："吴老坐化如此成功，堪称全国之最。"

