## 第一部分：边智中动功体系

### 一、传承源流

**华山道长边智中（边治中）传承陈抟丹道动功：中国道家养生长寿秘术**

边治中道长系中国道教全真华山派第十九代传师，中国道家古代养生长寿秘术传师，中国古代养生长寿术研究学会创会会长。

边治中道长原名边福生，山东济南人。二十世纪30年代初开始学道，皈依全真道华山派，列为第十九代传师（智字辈），道号"边智中"（后以谐音边治中行世），曾受该派第十八代传师冯礼贵道长亲传站、坐、跪、蹲、滚、爬、卧、行八类六十四套中国道家养生长寿秘术。

自这套功法公诸于世以来，已有汉、英、日、西等多种文字的著作遍及世界各地。《人民日报》报道认为："边治中道长倡导的'千古健身秘术'具有医药不能比拟的独特效果。"

世界著名生物科学家牛满江博士修炼此术后确认："是从中华民族悠久的历史宝库中挖掘出来的强身长寿的宝贵经验，从增加生命之源入手，是人体细胞养生术，应称之为'返老还童术'"。

**传承谱系：** 火龙真人 → 张三丰 → 吴云青 → 边智中（边治中）→ 邹通玄/邹通么

**编著者：** 苏华仁（吴云青师父赐道号：苏德仙）、唐明邦、边智中、赵中道、李静甫

### 二、七类功法总纲

中国道家秘传养生长寿术包括有 **站功、坐功、蹲功、跪功、卧功、滚功、爬功** 等七种功法。每种功法又分十三势。

每种功法都有男式（乾功）及女式（坤功）之分，学练者可按性别选练。

一般练功者，不必每次都要练完所有功法，只要根据各势功法的作用，对照自己身体的状况，选练其中几势即可。**初学者应首先练站功**。开始练时，可选择站功中的一两势先练。每天学练两次，每次3~5分钟。身体适应后，时间和次数可按个人的情况而适当增加。待练好站功，初见成效之后，再学练别的功法。**站功是养生长寿术的基础**。

上述七种功法中之卧功、蹲功、滚功、爬功和跪功需练功有一定基础，方可学练，故暂不在此书详介。

另一种分类法（表述有别但实质相同）：立功（站功）、坐功、蹲功、跪功、爬功、滚功和卧功。其中立功是养生长寿术的预备功，卧功是长寿术的核心。

### 三、站功全部势名称及核心要领

站功每势又分十三势（具体本书介绍的为以下十三势）：

#### 站功一势 回春功（服气养肾悠功）
- 此功有回春之力，故曰"回春功"。又功在服气养肾，所以又称"服气养肾悠功"。男称"悠肾囊功"，女称"顺阴功"。
- **功理作用：** ①最大限度吐故纳新（腹式深呼吸，增强横膈肌）；②调节内分泌机能，改善性激素分泌。
- **核心要领：** 全身放松，引体向上，屈身向下，作椭圆形运转，使大脑皮层处于保护性抑制状态，中枢神经得到调整和平衡。

#### 站功二势 上元功（挤阴功）
- 此功有增强元气的作用，故曰"上元功"。其特点是做功时用两腿根部挤压外生殖器，所以又称"挤阴功"。男称"挤肾囊功"，女称"挤肾阴功"。
- **核心要领：** 以两腿根部有节律地挤压外生殖器，配合呼吸，增强元气。

#### 站功三势 八卦形功
- 此功特点为双手在体侧划弧，其轨迹形似八卦，故曰八卦形功。
- **核心要领：** 双手在体侧划弧，轨迹呈八卦形，意念与动作相合。

#### 站功四势 鹏翔功（平环功）
- 此势动作如大鹏展翅翱翔长空，故曰鹏翔功；又因此功两手在体前转动划圆，其轨迹形似连环，所以又曰平环功。
- **核心要领：** 两臂如大鹏展翅，两手在体前转动划圆，牵动手掌商阳、少商、少泽、合谷穴和肩部肩髃及风池穴。

#### 站功五势 龟缩功（复环功）
- 此势做功时，重点动作是缩肩伸颈，形如龟状，故曰"龟缩功"。又因此功两手移动的轨迹是多个圆，其状如环环相套，所以又名"复环功"。
- **核心要领：** 缩肩伸颈，双手移动轨迹呈多个圆环相套。双手划圆时手指微屈，上行时手臂尽力前伸，后腿相应挺直。精力集中，目光随手转动；转体时主动收缩小腹，动作协调、柔顺、连贯。

#### 站功六势 龙游功（三环功）
- 练此功时，躯体扭动，形如蛟龙出水，卷屈层出，故称"龙游功"。又因两手在体前、体侧上下左右移动的轨迹是3个连续的圆，其状如环，故又名三环功。
- **核心要领：** 取龙的神态动作，脊柱被最大限度地拉开呈S形，头、颈及脊椎各关节顺龙游姿势协调而动，以腰为主宰带动躯干全身性柔动，调动任督二脉。
- **作用：** 主要活动躯干部位，使督脉调顺，防治脊椎骨刺增生，强腰健肾，减肥。

#### 站功七势 蟾游功（小环功）
- 古时金蟾为仙兽。此功动作模仿蟾蜍游泳的姿势，故曰蟾游功。又因此功动作主要是双手在身体的前下方来回划较小的圆，其轨迹如同两个小环，所以又名小环功。
- **核心要领：** 模仿蟾蜍游泳，双手在身体前下方来回划小圆。

#### 站功八势～十二势（其他各势）
书中所述为八至十二势（介于七势和十三势之间），均为站功组成，每种功法又分十三势。

#### 站功十三势 还童颜功（润肤功）
- 此势主要做功于头部，特别是颜面部位。久练此功可以使皮肤滋润、细嫩、富有光泽、减少皱纹不长暗疮和老人斑，故曰还童颜功，又称润肤功。此功共分14节。
- **核心要领：** 第一节三星高照；摩擦双手刺激劳宫、鱼际、合谷、十宣等穴位，牵动背部脊柱神经督脉诸穴。上起下落的提踵动作刺激下肢足三阳、足三阴六脉诸穴。刺激会阴、长强穴，调节改善性激素分泌。"若要还童颜，必须磨鹰爪"。

### 四、坐功6式名称

书中详细介绍了坐功的前三势：

#### 坐功一势 左右连环功
- 此势动作是使肚脐下半寸的起功点围绕肚脐，从左至右，从右至左连续划圆，故曰左右连环功。
- **做法：** 身体端坐平稳，胸上提，腰部挺直，两腿紧靠，两脚内收，脚掌前部着地，脚后跟微微抬起。两手掌心平放在膝盖上。轻微摇动腰腹部，使肚脐下半寸正中处的起功点围绕肚脐从左至右划寸圆，连续8次，再反向8次，配合腹式深呼吸。

#### 坐功二势 前后环功
- 此势动作是使肚脐下半寸正中处的起功点围绕肚脐，从前至后，从后至前连续划圆，故曰前后环功。
- **做法：** 预备势与左右连环功同。起势时使起功点从前至后划寸圆共8次，再从后至前划8次，配合腹式深呼吸。
- **作用：** 全身性环功，使经络活顺，气血畅通，调理督脉、任脉和脏腑器官。对于脑力劳动久坐者，是最理想的健身功法。

#### 坐功三势 坐平环功
- 此势动作是使肚脐左开半寸的起功点围绕肚脐，从左至右，从右至左划水平圆，故称坐平环功。
- **做法：** 身体端坐，双腿叉开，两脚与肩同宽，脚跟微抬，双手平放双膝上。轻微摇动腰腹部，使肚脐左开半寸的起功点围绕肚脐划水平圆。

（书中另有坐功其他各势，但因七种功法中卧功、蹲功、滚功、爬功和跪功需练功有一定基础方可学练，故在本书中坐功仅详介上述三势，统称为"坐功三势"可用于日常修炼。）

---

### 五、卧功3式名称

书中提到卧功是长寿术的核心，但"上述七种功法中之卧功、蹲功、滚功、爬功和跪功需练功有一定基础，方可学练，故暂不在此介绍"。

据传承体系记载，边智中道长受传的卧功体系包括多种睡功功法，源自陈抟一脉的卧功体系包含：
- 华山十二睡法
- 先天睡功
- 小修丹睡法
- 小搭桥卧功法
- 大搭桥卧功法
- 抱龙眠睡功法
- 张三丰睡丹诀

（因本书仅介绍基础站功和部分坐功，卧功、蹲功、跪功、滚功、爬功的具体势名与做法需有师传基础后方可学练，故书中未列明具体三式名称。）

## 第二部分：九转还丹功两套体系

### 体系一：《黄帝外经》九品功法（六位名师口传）

依据六位丹道名师口传《黄帝外经》、《老子道德经》、《周易参同契》内含中国道家内丹养生修真长寿学具体修炼下手功夫，共分九阶，即俗谓之"九品"，古称"九转还丹"。此九品之功法，内蕴性、命双修之大法。

#### 九品纲目
- **一品炼己：** 性如灰，心扫杂念；
- **二品筑基：** 止善地，固住本源；
- **三品按炉：** 采大药，文烹武炼；
- **四品结丹：** 在柢树，两大中悬；
- **五品还丹：** 过昆仑，降落会晏；
- **六品温养：** 玉灵胚，也得三千；
- **七品脱胎：** 须眉顶，婴儿出现；
- **八品悬殊：** 并六道，妙哉难言；
- **九品还虚：** 九载功，丹成九转。

---

#### 一品炼己功法
**功理：** "其要在炼性"。性功乃命功之基。性功主要是将自身"后天之识神"返回"先天之元神"，现出自身之本来之性。

**修炼方法：** 需习练者师乎造化、法乎自然，诚心以修道德（功德才智量五德兼备），视功名利禄与尘缘世事如浮云，参透世事，自身与天地合一，识神泰定，元神显明。

**秘传口诀曰：**
```
参透世事自定神，也无我相也无人；
缘人回光玄关窍，自有灵光贮此身。
```

---

#### 二品筑基功法
**功理：** 此乃命功筑基之大法。其目的主要是将后天之元气返回先天之元气，以为采取元精做好准备。

**修炼方法：** 筑基功以己性止善地（即真正之玄关窍）于子午卯酉四时，按师传一定之法、一定之度、一定之数精心、潜心修炼之，以达到可随时（即活子时）将自身的后天之气返回先天之气。

**秘传口诀曰：**
```
静则为阴动则符，功夫底是有沉谋；
倘若玄关无消息，动及风雷也算浮。
```

---

#### 三品按炉功法（采大药，文烹武炼）
**功理：** 此为命功（修炼元精）之首，习练者务须在自身先天元气浩然盈足的基础上，配以先天之元神，和以自身甘露，以文武火烹炼于丹田之内，以为结丹做好准备。

**修炼方法：** 三品功法务需因势按一定度数，在丹田之内留下清气，去掉浊气，将体内丹炉按稳，以便采药结丹。

**秘传口诀曰：**
```
古来金丹产鼎内，金丹全赖精气神；
文烹武炼师造化，终日乾乾闻捷音。
```

---

#### 四品结丹功法
**功理：** 其要在按炉已妥的基础上，将自身中的元精采于身内两大中悬的柢树（即丹田之炉内），随即和以先天之元精，配以先天之元气，然后将已采于丹田内的元精化为气结为丹，然后进行还丹。

**秘传口诀曰：**
```
心无我相无人相，忘掉众相总是长；
待到丹成九转后，心随物我一起忘。
```

---

#### 五品还丹功法
**功理：** 四品功确炼成之后，可进行还丹之功。还丹之功，仍需以先天之气吹动四品功夫所炼之丹，沿自身先天之路线，按名师所传的特殊功势，速将所结之丹过昆仑落会晏。

**功效验证：** 此功如确炼好，精气神三位一体凝成的丹，过昆仑落会晏时确实可听到鸟语啾啾，天籁声声；闻到花香阵阵，异香扑鼻……

**秘传口诀曰：**
```
终日乾乾得金丹，金丹不还为假丹；
龟蛇盘结坎离交，过海跨山落会晏。
```

---

#### 六品温养功法
**功理：** 五品功确炼成之后，可炼六品温养之功。温养之法，其要在文火温养，即以先天之元气，按一定之度数，将所炼之丹细细的慢慢的温养之。

**修炼方法：** 还丹之功需适时急速行功，故炼温养之功时需全身精气神放松，归于自然而然。

**秘传口诀曰：**
```
龟蛇盘结金丹还，温养神功归自然；
玄关引来三昧火，方可后天返先天。
```

---

#### 七品脱胎功法
**功理：** 六品功成之后，方可行七品之大功。此步功效甚大，习练者自身逐渐返呈出婴儿时模样。

**秘传口诀曰：**
```
脱胎至境非等闲，不是仙佛难至前；
圣胎脱去游八极，功德圆满童颜现。
```

---

#### 八品悬珠功法
**功理：** 七品功确炼成之后方可行八品之功，八品之功效又高于七品。八品之功效之一是双目呈碧蓝色，精光射人……

**秘传口诀曰：**
```
六道并一悬珠功，自然而然人天通；
其妙难言世间人，唯有仙佛可印证。
```

---

#### 九品还虚功法
**功理：** 九品功法之效比之八品更上一层楼。习练者如真能将其习炼精，则人与天地化为一，功德才智量五德兼备也，其功用难以估量也。

**秘传口诀曰：**
```
还虚之功非凡功，不是贤达岂容听；
其效神妙不可言，百兽闻之也通灵。
```

### 体系二：九节玄功火候（九转还丹功真传）

#### 九节玄功总纲

九节玄功者，古称九转还丹功：**筑基、炼己、采药、得药、进火、烹炼、温养、沐浴、退符**也。

此九节玄功要分为二阶段以行之：
- **第一段：** 筑基（第一节）、炼己（第二节）——未进道之人先修此二节，以为健康长生之根本。
- **第二段：** 由采药至退符，合共七节。

九节玄功每日定要做二次至三次，一次之功夫约量一点钟左右，同时定要做得透彻后，方可以休息起身。

**(以下为各节口诀与坐法详录)**

---

#### 第一节 筑基

**火候口诀：**
筑基者，建筑基础也。学道，必须先行人道，配合天道，行外功，作善事，守规戒，炼静坐，闭精血，定饮食，制睡眠，限劳动，弃妄想，以为修大道基础也。

**坐法：**
静坐之法，依照三种坐法：一双盘，二单盘，三普通自然盘。此三种坐法，由人随便选坐，此三法者，乃筑基初步坐法也。初步坐法，坐到心静，杂念消除，则伸出两脚，双手搭膝，此两脚伸直之法者，筑基心静之时，所用之法也。

筑基成功之证据：自然男不走精，女无月信。

---

#### 第二节 炼己

**火候口诀：**
炼己者，炼心制性也。使心欲无妄生，静中对境无心，一切假境，现于目前，一毫不着，即俗气全消矣。炼己之功，谓之炼心性，此功夫定要至死方休，在未成道之前，切莫放松炼己功程，恐有无明火，烧化功德林，则前功尽废矣。

**坐法：**
炼己坐法，两脚照原伸直，恐心意不定，合掌暗念佛号，求佛帮助。

须知炼己难，而还丹容易。炼己须要炼数年，心性能得早静者，身体早得健康，方有办法可炼道。

---

#### 第三节 采药

**火候口诀：**
采药者，筑基炼己功成，外功满，而人欲消，得到大自然之景象，静极之中，已有药物渐现，实时用采取之功夺之也。

须知采药，就是采取精液所化之真气，所谓金丹大药，并无物可形容，千言万语，亦是自身之浊精，由全身温暖之气，乃强烈之火候烧过，而成真种，由此方有真气可采也。

**坐法：**
采药坐法：佛号免念，玄关免守，两脚照原伸直，两手搭膝，静中求出甘露，真意顺甘露，而降下丹田，实时用真意，推出两腿，在脚尖拇指上面一寸三分高，随时吸先天虚无之气到玄关，在吸之时，眼要开一次，而鼻息亦要吸一回，开吸后，随时再降下甘露，同样推出两腿，二次照原，一吸一开，连续用三次。

**采药三火候比喻：**
- 第一次采药：如初三日之月，现刀圭之形（冬月建子）
- 第二次采药：如初八日之月，已成半面（十二月建丑）
- 第三次采药：如三阳开泰，月到十五日圆明光辉（正月建寅）

---

#### 第四节 得药

**火候口诀：**
得药者，得精化气谓之大药。

**坐法：**
照前节之坐法，两脚伸直，两手搭膝，心守丹田，再求甘露，真意再顺甘露，而降下丹田，实时推出两腿，脚尖拇指上面，以免吸回。口诀以采药之后，不吸气者何也？因回光有火，吸气有风，风火交加，必损药苗也。所以不回不吸，约量引出三寸香久，连推连降，有三十六回左右。推得阴尽，心自静，身自轻，全体舒畅爽快，四相忘形，膀胱如火，两肾即丹田如汤，相貌如痴，甘露如蜜——此时紧急进火，运法轮之功也。若贪其轻爽，则损药苗，而大丹不能结矣。

---

#### 第五节 进火（运周天）

**火候口诀：**
进火者，运周天，行法轮之名也。进火之法，即用真意（精神力、心之思想力），运用丹田之热气，使其周流全体。所谓热气即阳气，寒冷之气即阴气。人身有一分温气即不死。

**坐法：**
两脚收回，照初步筑基之坐法。大药元气已凝结在丹田，紧急用真意，顺甘露而降下丹田，将丹田之药物（金丹舍利元气）用真意引对尾闾关，而上夹脊关，直透玉枕关，运上昆仑顶，将所运之温暖之气一并载于玄关之中，约量守数分钟。再继续第二回，再降下甘露，运过三关，到玄关再守数分钟，连运三次，以待烹炼之功。

---

#### 第六节 烹炼

**火候口诀：**
烹炼者，譬如凡人饮食之煮饭也。煮饭起初定必用猛火而煮，若无用猛火煮者，米定不能成饭矣。所以药物已得，若无用进火行法轮之功运上玄关烹炼，定不能成金丹舍利也。

烹炼必须不迟不速，以呼吸定其法。进火亦名运周天。行法轮之时，神气必须与甘露而同行。

**坐法：**
照前节筑基之姿势，六神统一于玄关，守药物。立刻用起枷子，大开神光，两眼圆神观窍，用最大力量，两手速力，将那浊精、识神、游魂、鬼魄、妄意一切炼退。烹炼大药约量数分钟就可以（并看年龄由自己分定，恐药物烧化）。

**文武火候：** 武火者，呼吸之息强烈，谓之武火；微细谓之文火。年青人气旺精血猛强，多用武火；老年人气弱，多用文火温养。

---

#### 第七节 温养

**火候口诀：**
温养即是温养圣胎，实喻保守此元气之不散也。前节既采得金丹大药，逆运河车，转大法轮，透过三关，载于玄关，用烹炼之功，炼化阴神、识性、妄念。自此神光寂照，须臾不离，合成虚境。

温养圣胎乃专一，犹如鸡抱卵之至诚，恰似龙含珠，时时静守玄关窍，免得炉中水火寒。须防危险——此时阳气未纯，余有阴气未尽，须防之。

**大小温养：** 小温养乃每日每时之温养保守；大温养须经过九年面壁功夫，方得本性圆明而出圣胎。

**坐法：**
照最初筑基坐法。枷子放下，眼漏一线之光，守玄关，约量数分钟，就可以沐浴。此时最忌妄念。武火不用，全用文火。一呼一吸，随其自然，亦不着而存心意，又不放心意，则不使阴魔作祟，炼阴保阳，而金丹自固矣。

**口诀联：**
```
武火烹兮文火温，呼吸有无自然存。
武武文文调合際，永固长生不老根。
```

---

#### 第八节 沐浴

**火候口诀：**
沐浴乃是圣胎结就，即元气已经聚会，须防其危险。防其心念不定，畏此阳气未纯也；虑其意念不静，怕此阴气未尽也。

洗心涤虑，正是寂而常照，此为沐浴之首务。沐浴者，乃洗涤其心，能知此意，则能转识成智。三万刻中无间断，行行坐坐转分明——此为法轮常转，息息归根。

**坐法：**
盘坐就可，两手搭膝在腿上。此时玄关免守，全心放空，两脚放开亦可用。两眼自然，上不守玄关，下不守丹田，舌免搭天桥，停几分钟可以退符。

**口诀联：**
```
防其心欲洗灵台，涤清妄念真仙诀。
素黑归白尘秽无，得见本性明朗活。
```

---

#### 第九节 退符

**火候口诀：**
何谓退符，乃是退阴符也。未出胎神之前，体中有阴气，必须用退符之功。

退阴符于两足弯，因留下火种，以待下次炼丹之用也。若退符在脚尖者，已无火种矣。所以退在足弯，乃留下次之火种也。

退符三回以后，起身留意，切莫胡思乱想。行住坐卧，须臾不离，念兹在兹，时时在道。外则三宝——眼耳口闭塞，自然功夫日进，胎神日足，待气足神明，能脱胎神化。

**坐法：**
两脚伸直，两手搭膝，求生甘露。此时心意顺甘露而降下丹田，再推出两腿足弯，连推三回，以免吸回收入。

**口诀总结：**
```
诸子对此九节玄功，时时刻刻要详细静观，自有妙理出现。
此九节玄功，谓道之全盘口诀，自进道以至了道，无不备此中矣。
```

（第九节：退符，古传为张果老祖师传授）

## 第三部分：九转还丹功补充明细之解说（全盘总口诀）

九节玄功者：筑基、炼己、采药、得药、进火、烹炼、温养、沐浴、退符也。

**筑基、炼己二者为第一段**：未进道之人先修此二节，以为健康长生之根本，方可做大道之基础。炼己之功不可急，须炼数年，心性能得早静者，身体早得健康。

**由采药至退符合共七节为第二段**：此初步每日定要做，须勤采，而继续转法轮之功夫不断。

**最终旨要：** 若能做到心肾合一，则阴阳会合后，此九节免做，只用文火保守，守至本性明朗，自能脱胎飞升。
